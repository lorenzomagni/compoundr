A single labelled figure with an optional change and caption, for KPI rows.

**Consumer provides:** `label` (short, sentence case; it is uppercased by `overline`), `value` (a pre-formatted string such as `$184.20`), optional `delta` (a number, rendered by Delta) and `caption`.

- The value is set in `figure-lg` mono; format it per the Data display section.
- Keep to four Stat tiles per row on desktop, separated by `space-8`.
- Always give a caption that names the comparison ("vs 5Y avg"); a delta with no baseline is noise.
